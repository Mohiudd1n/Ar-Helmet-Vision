To add one, drop a `.glb` here, add it to `src/data/helmets.js`, and calibrate its fit in the
Fit Studio (`#/studio/<id>`). The Unity app copies these files in via
*Tools ▸ AR Helmet Vision ▸ Import Helmet Models*.
